# Preview a fixed replacement before writing

The caller supplies the original source and a separate directory prefix, nonempty literal and replacement. Preserve the approved fixture-v1 budgets, canonical framing and conservative dependencies. The default CLI request is a caller-stated task, not an assertion that a human approved the scope. A self-authored request cannot certify independent user intent. No portable Writfold report or workflow receipt schema is being frozen.

Given the *whole* admitted fixture, enumerate references using the exact same qualified discovery path as `refs`. Map each reference to the immutable source bytes at that path and range. Lower same-resource edits to the retained, pinned Splicery dependency, use its actual `prepare` order in `render`, and preserve every untouched path and byte. Compare the complete candidate against the independently supplied task, not just the subset displayed. Refuse excess work, overlap, mixed subjects, dropped negative witnesses, extra edits or mismatched candidate bytes. Expose a deterministic review identity binding base, task, complete candidate and checker profile; apply must recompute against the intended source and compare the exact reviewed identity. No writes from preview. Distinguish matches, changed bytes and no change. Proofs cover selected production decisions only; digest framing, host input and lowered cuts remain separately qualified.

The precise live publication effect belongs to a separate reviewed RFC and milestone. Writfold may retain the output of a configured command; it independently owns the gate result, guard policy and receipt. Recheck that division at milestone exit.
